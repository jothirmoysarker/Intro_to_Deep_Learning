# Deep Learning Fundamentals

A practical introduction to deep learning and neural networks, covering the fundamental concepts, algorithms, and techniques designed by Kaggle, which are used to build and train deep learning models.

This repository combines theoretical concepts with hands-on implementations to develop a strong foundation in deep learning.

You can find the official Kaggle course here: [Intro to Deep Learning](https://www.kaggle.com/learn/intro-to-deep-learning)
